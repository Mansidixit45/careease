# CareEase – Online Healthcare Consultancy System

## Overview
CareEase is a full-stack healthcare consultation platform that enables patients to connect with doctors and book appointments online.

## Tech Stack
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## Features
- Admin, Doctor & Patient Authentication
- Appointment Booking System
- Patient & Doctor Management
- CRUD Operations
- Responsive User Interface
